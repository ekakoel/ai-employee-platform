# Feature: Home & Inbox command center

## Home
Role-aware overview: greeting, stats, **quick actions** filtered by permissions, needs-attention list, recent tasks, agents.

| Role | Typical quick actions |
|------|------------------------|
| Owner | Users, Hire AI, Knowledge, Inventory, Tasks, Approvals |
| AI Admin | Hire AI, Users, Knowledge, Inventory, Policies |
| Reservation | Chat, Tasks, Inventory, Inbox |
| Manager | Inbox, Approvals, Tasks |
| Contract Manager | Knowledge, Chat, Tasks |

Demo readiness checklist is shown to Owner / AI Admin / Manager.

## Inbox
Unified queue: pending approvals, open tasks, handoffs. Tabs: Needs action / In progress / All open.

## Path
```
Home → quick action → feature page → back to Inbox for approvals
```
